# RELXTAN Official Website V4

GitHub Pages 独立 HTML 版本。

## 特点
- 不依赖 assets 文件夹
- CSS / JS / RELXTAN Logo / favicon / 微信二维码全部嵌入 HTML
- 适合直接通过 GitHub 网页端上传
- 多页面响应式企业官网
- 现有 5 个 GitHub 工具已接入
- AI 智能运营、Shaun AMZ Skills、Codex 落地、私人定制均已独立展示

## 上传方法
1. 解压 ZIP。
2. 删除仓库旧 HTML 文件（也可直接覆盖）。
3. 把本目录全部文件上传到 `relxtan` 仓库根目录。
4. 确保 `index.html` 在根目录。
5. 等 GitHub Actions / Pages deployment 变绿色。
6. 打开：
   https://shuranyang211-ai.github.io/relxtan/

如果浏览器仍显示旧版，按 Ctrl + F5 强制刷新。
